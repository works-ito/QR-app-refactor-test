# QR在庫管理｜開発・検証版

株式会社ワークスのQR在庫管理アプリを、安全に改修・検証するための開発用リポジトリです。

> **このリポジトリは現場の本番環境ではありません。**  
> 新機能、修正、動作確認はここで行い、確認後に本番へ反映します。

## 現在の位置づけ

- リポジトリ名：`QR-app-development`
- ブラウザ表示：`QR在庫管理｜開発版`
- 本番リポジトリ：`QR-app-ver.2`
- 本番版と基本構成を揃えながら、次の変更を先行して検証します

## 主な機能

- 通常受付／イレギュラー受付
- 個体管理品・簡易個体管理品・REC・数量管理品への対応
- QR連続読取と最新状態の照合
- 二重出庫・不正な状態遷移の防止
- 数量管理品の検品、完成機・検品廃棄への振り分け
- 一括送信と5分以内の送信取消
- 出庫・返却写真の保存
- 伝票写真から顧客名・現場名をAI解析

## RECの取扱い

- `REC01-001` などの通常作業は個体管理品として処理します
- 校正中・校正完了・交換完了のみREC専用処理です

## 主なファイル

- `datamatrix-test.html`：本番構成と揃えた統合画面
- `index.html`：開発・確認用の入口
- `styles.css`：画面デザイン
- `app.js`：画面制御・QR読取・GAS連携
- `version.json`：キャッシュ更新用バージョン

## 開発の流れ

1. このリポジトリで変更する
2. 構文エラーを確認する
3. スマホとPCで表示・動作を確認する
4. GAS連携とスプレッドシート反映を確認する
5. 問題がなければ `QR-app-ver.2` へ反映する

本番へ反映するときは、関連ファイルとバージョン番号を揃えます。GASを変更した場合は、GAS側の保存と新バージョンのデプロイも必要です。
